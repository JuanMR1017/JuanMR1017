## 🚀 Proyecto actual — FOTON-IA

Participo en **FOTON-IA**, un proyecto de monitoreo inteligente para la valorización energética de aguas residuales en el Valle de Aburrá.

Mi contribución se ha enfocado en la integración y validación de componentes de la arquitectura IoT, incluyendo:

* Adaptación y dockerización del simulador LoRaWAN **SUPG**
* Integración con **ChirpStack Gateway Bridge**
* Comunicación mediante **Semtech UDP**
* Integración con **MQTT / Mosquitto**
* Validación del flujo de comunicación hasta ChirpStack
* Documentación técnica del proceso
